# Лабораторная работа 3. Условия и логические выражения

## Как запустить
Убедитесь, что установлен Python 3.13+. Откройте терминал в папке с файлами и запускайте:
`python minimum.py`, `python calculator.py`, `python point.py`, `python variant.py`.

---

## Таблица проверок

### 1. `minimum.py` (Минимум трёх чисел)
| Ввод (a, b, c) | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| (2, 10, 3) | 2 | 2 |
| (5, 5, 5) | 5 | 5 |
| (-4, 0, -2) | -4 | -4 |
| (10, 20, 1) | 1 | 1 |

### 2. `calculator.py` (Калькулятор)
| Ввод (a, b, операция) | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| (7, 2, `/`) | 3.50 | 3.50 |
| (5, 0, `/`) | Деление на ноль запрещено | Совпадает |
| (5, 2, `?`) | Неизвестная операция | Совпадает |
| (3, 4, `+`) | 7.00 | 7.00 |
| (10, 4, `-`) | 6.00 | 6.00 |
| (6, 7, `*`) | 42.00 | 42.00 |

### 3. `point.py` (Прямоугольник)
| Ввод (x, y) | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| (2, 2) | Внутри или на границе | Совпадает |
| (5, 3) | Внутри или на границе | Совпадает |
| (5.1, 3) | Снаружи | Совпадает |
| (-1, 0) | Снаружи | Совпадает |
| (0, 0) | Внутри или на границе | Совпадает |

### 4. `variant.py` (Вариант 1: Заряд аккумулятора)
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| -1 | Ошибка диапазона | Совпадает |
| 0 | Низкий | Совпадает |
| 19 | Низкий | Совпадает |
| 20 | Средний | Совпадает |
| 79 | Средний | Совпадает |
| 80 | Высокий | Совпадает |
| 100 | Высокий | Совпадает |
| 101 | Ошибка диапазона | Совпадает |

### 5. `leap_year.py` (Високосный год)
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| 1900 | Нет, не високосный | Совпадает |
| 2000 | Да, високосный | Совпадает |
